# Bundle Update Log

## 2026-11-06
* **Update**: `okf.py drift` now re-reads a remote's current default branch on every fetch when a [Code repositories](/SCHEMA.md) row leaves `branch` blank, so switching the primary branch upstream shows up as moved pins instead of drift silently tracking the old one; branch names containing `/` also resolve correctly. Documented in [SCHEMA.md](/SCHEMA.md) and [okf-toolchain](/entities/okf-toolchain.md) (pin restamped).
* **Update**: multi-project bundles. A directory inside the bundle holding its own SCHEMA.md is now a *project scope* with its own type registry (names not inherited — OKF registers no types centrally), directory layout, tags, review cadence, `index.md` and `log.md`; the root SCHEMA keeps only the rules no project may loosen and the root log only team-level changes. Code in other repositories is pinned by `repo:` + `path:` + `blob:` against a `# Code repositories` table in SCHEMA.md, and `okf.py drift` checks it through blob-less depth-1 clones under .okf-cache/ (lint reads the cache only). Conventions in [SCHEMA.md](/SCHEMA.md); toolchain in [okf-toolchain](/entities/okf-toolchain.md) (pin restamped); project-aware Step 0 in [lifecycle-skills](/entities/lifecycle-skills.md) (pins restamped); team-wiki guidance in [adopting-the-bundle-pattern](/concepts/adopting-the-bundle-pattern.md). A bundle without project SCHEMA.md files behaves exactly as before.

## 2026-08-27
* **Update**: fixed a provenance hole in [kb-review](/entities/lifecycle-skills.md) — the rewrite verdict advanced only `generated.at`, so a rewrite by a different agent kept the previous producer in `generated.by` and misattributed the new text. `generated` is now replaced wholesale as one provenance event, stated in both the skill and [SCHEMA.md](/SCHEMA.md).
* **Update**: wired up the v0.2 `generated: { by, at }` trust field — kb-ingest now stamps it on every page it writes or materially rewrites (`<tool>/<version>`, today), kb-review advances it when it rewrites claims, and lint validates the shape of `generated`/`verified` when present. Absence is deliberately not warned: an unstamped page honestly records that nobody claimed authorship, and a presence warning would push queue-clearing into inventing records. `generated` (what produced it) and `verified` (who confirmed it) are kept strictly apart in [SCHEMA.md](/SCHEMA.md) and [okf-toolchain](/entities/okf-toolchain.md).
* **Review**: flagged [openwiki](/entities/openwiki.md) and [openwiki vs the kb bundle](/comparisons/openwiki-vs-kb-bundle.md) `needs_review` — openwiki 0.4.2 emits OKF v0.2, tracks Grounded Claims evidence, and installs into coding agents, contradicting the "own format / no per-page lifecycle" claims sourced from the 2026-07-12 capture. Bundle-side rows corrected in place; the openwiki side needs a fresh capture (kb-ingest).
* **Update**: evidence pinning + `okf.py drift` (borrowed from openwiki Grounded Claims, rebuilt on git). A `sources` entry may pin a re-readable repo file with `blob:`; `drift` re-hashes it and lint warns when it moves, making review signal-driven instead of calendar-driven for anything the repo can answer. Distinct from the sha256 `drift` removed the same day, which compared a file against a hash stored in itself — see [okf-toolchain](/entities/okf-toolchain.md). Pins added to [lifecycle-skills](/entities/lifecycle-skills.md) and [okf-toolchain](/entities/okf-toolchain.md); cadence rules retuned in [SCHEMA.md](/SCHEMA.md); the `code_refs` proposal in [codebase-memory-mcp vs the kb wiki](/comparisons/codebase-memory-mcp-vs-kb-wiki.md) is now partly built without the MCP server.
* **Update**: migrated the whole bundle to **OKF v0.2**. `status` now carries only the standard `draft|stable|deprecated`; the five-state machine moved to a `lifecycle` extension key derived from it (lint errors if they disagree). `review_after` → `stale_after`; `sources` entries are now mappings with `resource`/`id`/`title`; the `# Citations` sections are gone, claims cite `[source-id]` inline; `index.md` declares `okf_version: "0.2"`. Conventions rewritten in [SCHEMA.md](/SCHEMA.md), lifecycle wording in [knowledge-lifecycle](/concepts/knowledge-lifecycle.md).
* **Ingestion**: OKF v0.2 spec from [capture](/sources/2026-08-27-okf-spec-v0-2.md) — the format moved to its own repo (GoogleCloudPlatform/open-knowledge-format) and the knowledge-catalog copy is a frozen snapshot; rewrote [open-knowledge-format](/concepts/open-knowledge-format.md) for v0.2 (standard provenance/trust/lifecycle families, actor convention, breaking changes from v0.1).
* **Refactor**: Removed the `sha256`/`drift` ceremony from [okf.py](/entities/okf-toolchain.md) — git history is now the stated tamper record for [/sources/](/SCHEMA.md). Updated the lifecycle skills, SCHEMA source template, and every page describing the old drift model.
